# TrafficEase Hackathon MVP

A responsive frontend-only TrafficEase demo built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or import the folder into Replit.

## Included
- Modern responsive landing page
- Interactive demo map
- Traffic/accident/construction pins
- Route demo modal
- Issue reporting form
- New reports appear instantly in the alerts section
- Toast notifications
- Mobile-friendly layout

## Production upgrades
For a real hackathon backend, add:
1. Firebase Authentication
2. Firestore for reports
3. Google Maps or OpenStreetMap/Leaflet
4. Geolocation
5. Push notifications
6. Government/open traffic data
7. AI-based traffic prediction
